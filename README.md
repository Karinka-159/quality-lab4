# Quality Lab 4

Учебный проект для лабораторной работы №5: CI/CD пайплайн с quality gate.

![Quality Gate](https://github.com/Karinka-159/quality-lab4/actions/workflows/quality-gate.yml/badge.svg)
![Coverage](https://codecov.io/gh/Karinka-159/quality-lab4/branch/main/graph/badge.svg)

## Скрипты

- `npm run lint` — ESLint
- `npm run test` — Vitest
- `npm run test:coverage` — Vitest с покрытием
- `npm run e2e` — Playwright E2E-тесты
